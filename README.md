# LLMs-for-Optimization-Problems
Given the Job Shop Scheduling (JSSP) instance, How to produce a schedule that respects job precedence constraints (operation order within each job) , machine capacity constraints (one operation at a time per machine) and minimizes makespan (total completion time).

## Introduction To Problem
The Job Shop Scheduling Problem (JSSP) is a fundamental combinatorial optimization challenge with significant applications in manufacturing, logistics, and cloud computing. The objective is to schedule a set of jobs, each consisting of a sequence of operations across a set of machines to minimize the total makespan Cmax, subject to strict precedence and machine-capacity constraints
